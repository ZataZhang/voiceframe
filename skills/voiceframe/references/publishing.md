# 平台上传与发布

用于用户要求把现有成片上传、保存草稿或发布到视频平台。默认走创作者网页，不要求先申请开放平台 API。本文是操作约定，抖音上传到编辑页已实测（见下方记录），哔哩哔哩网页流程尚未实测；不代表内置发布脚本或已验证的完整自动集成。

## 输入与授权范围

从当前项目、交付记录和用户指令确定成片路径、目标平台、账号以及操作终点。制作完成不自动触发上传；用户说“上传”时默认完成视频、封面、标题和作品描述的上传填写，并使用平台草稿按钮暂存，核实保存结果。只有明确要求“发布/投稿”才正式提交；“不要发布”“先暂存”优先于较早的发布授权。用户已明确授权具体作品和平台的正式发布时，按该授权完成，不重复确认；当前宿主要求的确认仍须遵守。

已有最终成片时直接进入发布流程。检查文件存在、可播放、版本正确，读取时长、尺寸、编码与大小。平台限制以当前上传页面或官方说明为准，不固化易过时的大小和时长上限。确需转码或改画幅时保留原始成片，另存平台版本，避免直接裁掉关键内容。

准备标题、简介、话题/标签和可用封面，优先沿用用户文案与项目内容；缺少普通文案时可据此起草。原创/转载、来源、分区、商业推广、AI 内容声明、可见性和定时发布等设置须符合实际与用户意图，无法推断的必要信息先澄清，不为了通过表单随意选择。平台选择与账号冲突时先解决，不默认跨平台全发。

## 双封面与作品描述

抖音默认准备竖封面 **3:4** 和横封面 **4:3**，建议输出 1080×1440、1440×1080；以当前页面的实际格式和尺寸限制为准。其他平台按其封面要求生成对应版本，不统一强加双封面。

优先复用用户确认的封面；没有封面时根据剧本、标题、分镜或成片截图生成，两版保持配色、主体和短标题一致，分别构图，不直接拉伸或裁掉文字。使用当前环境可用的图片生成技能，遵循用户指定的服务及对应授权要求；百炼可使用 `bailian-gen`，宿主图片工具可使用 `imagegen`，没有生成工具时说明能力缺口。不要将这些技能的绝对安装路径写入项目，也不要默认他人已配置服务或允许计费。

生成后读取两张图，检查真实尺寸/比例、中文文字准确性、可读性、主体完整性和安全边距。发现错字、关键内容被裁或两版不一致时修正后再上传。封面标题忠于视频内容，不夸大；测试视频明确标为测试。按当前工具支持方式输出独立 PNG/JPEG 文件，例如 `cover-portrait-3x4.png` 和 `cover-landscape-4x3.png`。

标题和作品描述按实际内容撰写：标题短而清楚，描述说明视频核心内容及必要背景，可带相关话题；测试素材使用测试说明，不能编造正式作品内容。普通文案可依据项目自行起草并完成填写，事实、来源和声明不确定时澄清。记录实际填写文本，按页面字数限制检查截断。话题如需平台实体关联，使用页面的添加话题功能并核实，不把纯文本 `#` 当成已关联标签。

抖音竖封面与横封面分别进入对应“选择封面”编辑器，选择本地上传，核对裁切预览并确认；重新读取主页确认两处封面已替换。两张都完成并填好描述之后，点击 **“暂存离开”**（其他平台使用实际草稿保存按钮），核实提示或草稿列表；必要时重新打开目标草稿检查标题、描述及双封面仍存在。没有保存证据不能报告已暂存。暂存按钮不等于发布按钮，禁止为保存草稿点击“发布”。

## 浏览器与登录

- 默认 **Microsoft Edge**，用户明确指定其他浏览器或已有会话时遵循其选择。先读取当前宿主浏览器工具文档及可用浏览器/标签页，优先绑定目标平台已有标签页，避免重复打开或覆盖未完成草稿。
- 浏览器操作使用宿主支持的接口（如 `cua_repl`），按首次调用规则与实际返回文档操作。只有当前技能和工具确实支持所选浏览器时才调用辅助技能；例如 Jev 的 Chrome/IAB 限制不能用于 Edge。不把某个宿主的 API 或选择器当作跨环境通用实现。
- 若浏览器接口不可用，区分“工具未暴露”“Edge 未连接”“标签页不可访问”与“网页未登录”。说明实际错误与已检查的范围；工具支持原生 Edge 应用控制时可按其文档尝试，否则保留发布材料并报告连接障碍。不擅自换浏览器、复制 Cookie 或启动独立驱动来绕过连接问题。
- 打开目标上传页后观察当前页面。账号标识与可用上传编辑器是登录证据；仅有目标 URL、用户说已登录或此前成功记录不足以证明本次会话有效。遇到二维码、登录表单、登录跳转或明确未登录提示时，请用户在所选浏览器内完成登录，保留该页，暂停依赖登录的操作。
- 登录、验证码与扫码由用户完成；不索要密码、短信码、Cookie 或令牌，不把登录信息写入项目。用户告知完成后重新读取页面，确认编辑器和目标账号后继续。超时、未回复或刷新不等于已登录，不循环催问或轮询。
- 账号身份明确且与用户选择一致时沿用；身份无法辨认、账号不符或存在多账号歧义时先澄清。上传中途登录失效也按上述流程恢复，并先检查已有草稿和上传进度。

## 逐平台操作

1. 阅读新鲜页面状态，识别上传入口和实际支持的文件选择方式。使用工具文档允许的上传接口或系统文件对话框，不捏造文件路径控件、隐藏接口或固定选择器。每次操作后重新观察再决定下一步。
2. 上传指定成片，等待页面明确显示上传与处理完成。进度完成不等于转码完成或投稿成功。平台拒绝文件时读取具体错误，再处理格式或规格问题。
3. 按“双封面与作品描述”准备并上传对应封面，填写标题、作品描述和必要设置，检查预览、标题/简介是否被截断、账号、可见性与提交方式。多个平台可以复用成片，字段和声明按各自页面处理，不能直接照搬设置。
4. 用户只要求上传/准备时，使用页面支持的草稿保存方式并核实；没有可靠保存证据时说明“编辑器已填写，草稿保存未确认”。明确授权正式发布时提交；缺少必要授权时先完成可审阅内容，再请求所缺授权。
5. 提交后读取结果页或内容管理页，记录作品标识/链接及实际状态。区分“上传完成”“草稿已保存”“投稿成功/审核中”“已公开”“失败”；审核中不报告为已公开。

发布点击超时或结果不明时，先查内容管理/草稿列表核对账号、标题、时间与成片，确认是否已有作品再决定重试。无法排除已提交时停止重复发布并报告不确定状态。多平台中一个失败时保留其余成功记录，只处理失败项，不重发全部。

## 平台入口与差异

| 平台 | 入口 | 需要关注的差异 |
|---|---|---|
| 抖音 | `https://creator.douyin.com/creator-micro/content/upload` | 当前创作者上传编辑器；核对标题/作品描述、话题、封面、可见性、声明及即时/定时发布，以实际页面为准 |
| 哔哩哔哩 | 创作中心 `https://member.bilibili.com/`，从当前页面进入视频投稿 | 核对分区、标题、简介、标签、封面、原创/转载及来源；多分 P、声明和定时设置仅在适用时处理 |
| 其他平台 | 用户提供的官方创作者入口，或通过官方站点发现 | 复用浏览器、登录、上传、预览、授权和结果核实流程；页面有不支持的控件时明确交给用户完成该步 |

这些入口用于导航，页面会变化。为新平台添加适配时记录官方入口、特有必填字段、草稿与成功证据及实测日期，不默认套用抖音表单，不声称未经实测的平台已验证。

### Edge 探测记录（2026-10-07）

当前宿主的浏览器标签页接口未连接 Edge，但原生应用控制可以通过 `/Applications/Microsoft Edge.app` 访问现有标签页。使用 bundle ID 可能因 EdgeUpdater 留有多个版本而报歧义，此时可用当前安装的完整应用路径（其他系统按实际安装位置确定）。

首次读取抖音上传页时可访问性树与截图为空白；后续读取成功显示上传编辑器，不能据首次空白判断未登录。第一次文件选择阶段出现窗口焦点切换，未完成上传；用户将抖音窗口保持在前台后，已成功完成下列流程：

- 绑定原生 Edge，读取抖音上传页；点击“上传视频”打开 macOS 文件选择框。
- 在文件列表中点击测试 MP4，重新读取状态确认该文件被选中且“Open”可用，再点击“Open”。本次使用文件列表选择，未依赖路径输入快捷键。
- 进入 `/creator-micro/content/post/video?enter_from=publish_page` 编辑页，填写标题“Voiceframe上传测试（未发布）”。页面明确显示“上传成功”，视频预览与账号公开标识 `zt` 可见。
- 测试文件是本地生成的 6 秒、720×1280、H.264/AAC MP4，约 4.8 MB。保持未发布编辑页，未点击“发布”或“暂存离开”；未验证草稿持久保存、正式发布或未登录恢复。发文助手检测与 AI 封面生成独立于文件上传完成，不能据上传成功推断这些任务也完成。

多窗口或用户同时操作导致焦点改变时，停止当前键盘输入，重新观察并核对目标窗口；不得向其他页面输入文件路径或文案。无法稳定恢复时明确报告阻塞，不把点击文件项当作上传成功。使用新鲜可访问性状态里的文件项与确认按钮可以避免本次路径快捷键引起的焦点问题；不要复用本次元素编号。

### 双封面与暂存续测（2026-10-07）

使用百炼 `qwen-image-3.0` 生成两版测试封面，原始输出为竖版 1728×2368、横版 2368×1728，接近但不是精确比例。分别在抖音封面编辑器上传，经平台 3:4 / 4:3 裁切预览确认文字与主体完整；点击“完成”后主页显示双封面及“封面效果检测通过”。不能仅凭生成请求的比例参数推断文件真实比例；需要精确文件比例时另行调整或重新生成并检查结果。

标题为“Voiceframe上传测试（未发布）”，描述为“这是一段 6 秒的测试画面，用于验证 Voiceframe 在 Edge 中上传视频、设置 3:4 竖封面与 4:3 横封面、填写作品描述及保存草稿的流程。仅作功能测试，暂存不发布。”。点击“暂存离开”后返回上传页，出现“你还有上次未发布的视频，是否继续编辑？”与“继续编辑”入口，作为本次暂存的页面证据。尝试重新打开时窗口焦点转到其他窗口，因此未验证重新打开后的双封面/描述、云端草稿列表或跨会话恢复；正式发布也未验证。此续测补充上面的首次上传记录。
