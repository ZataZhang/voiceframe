# Voiceframe 视频制作

围绕成片组织工作：文案 → 剧本与画面草稿 → 音轨 → 时间轴 → 素材与画面制作 → 剪辑合成 → 检查与交付。用户只要求某个阶段时，完成该阶段即可。

## 选择应用与工具

先读取项目简报、现有工程和用户指定的应用。保留已有工具选择，不自动迁移工程或指定某个框架为默认。一个项目可用多个应用：配音、生成素材、动画制作、剪辑和导出分别选择。

用户未指定时，根据素材类型、编辑需求、可用工具与交付格式选合适路径，并在 `PRODUCTION.md` 记录理由、输入输出与阶段交接。仅在工具选择会实质改变结果且无法推断时澄清。阅读 [制作与交付](references/production.md)。

## 工作流程

1. **剧本与画面草稿**：阅读 [分镜与脚本](references/storyboard.md)，产出 `BRIEF.md`、`frame.md`、`STORYBOARD.md` 与 `SCRIPT.md`。先定叙事与构图，时长先作为估值。分镜描述观众看到的内容，不强制 HTML、代码动画或特定工程格式。
2. **审稿**：提供剧本与画面联络表，按已有草稿确认约定获得确认；已有确认或用户明确调整流程时按当前授权执行。概念图用于确认构图与风格，最终文字、数据须核对来源。
3. **音轨**：AI 配音可用 [百炼配音实现](references/tts-voice.md)，也可使用用户选择的服务；自录音频阅读 [音频后期](references/audio-post.md)。后者尚未实测，先验证短片段并试听。
4. **时间轴与制作**：测量实际音轨时长，回填分镜边界。按 [制作与交付](references/production.md) 在选定应用中组织素材、场景和音轨，长片分章节。
5. **检查与交付**：采用对应应用的检查方法，核对音画同步、文字数据、字幕、字体、画幅、音量与导出参数；审阅草片后交付最终视频及约定的可编辑工程。
6. **上传与发布（用户要求时）**：阅读 [平台发布](references/publishing.md)。默认使用 Edge，先确认工具可访问目标浏览器，再检查平台登录状态；未登录时交给用户登录，完成后重新检查。支持直接从已有成片开始，不必重跑制作流程。准备平台封面（抖音为 3:4 竖封面与 4:3 横封面）、标题和作品描述，一并上传填写；默认暂存并核实草稿，明确授权正式发布时才提交，逐平台记录结果。

按阶段与所选应用读取参考文件。

## 工具专属实现

- **百炼配音**：内置 [gen_voice.py](scripts/gen_voice.py) 默认使用既有偏好 `qwen-audio-3.1-tts-flash` + `xunanchuan_v3.1`，可配置模型和音色。仅在使用该服务时遵循可用的百炼技能与协议。持续失败时停止并报告。
- **HyperFrames**：仅在选用它时读取 [适配指南](references/adapters/hyperframes.md)，使用 HTML 模板及对应技能、lint/check、seek 与本地资源规则。这些规则不适用于其他应用。
- **其他应用**：使用其可用连接器、CLI、技能或工程规范。暂无内置适配时不要声称已支持自动导入；可交付中立素材包与人工交接说明，明确尚需在目标应用完成的步骤。

## 内置模板与工具

[init_project.py](scripts/init_project.py) 默认复制 [通用项目模板](assets/project/BRIEF.md)，包含简报、设计、分镜、口播与制作交接记录；只有显式 `--adapter hyperframes` 才附带该应用的 HTML 骨架。详见 [模板使用](references/templates.md)。

音频索引使用相对媒体路径与秒数，可供不同应用读取或人工对齐，不代表任何应用已具备自动导入。保留原始媒体、事实来源、授权和必要的导出记录。当前用户要求优先于既有项目约定。
