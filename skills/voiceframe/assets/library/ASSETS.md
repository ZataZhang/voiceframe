## 填写规则

**「内容」写画面里实际有什么**，不复读文件名。这是本库唯一有检索价值的列——下一个项目的人靠它判断「有没有能用的镜头」，而不是靠文件名猜。

例：`电路板微距，绿色焊点与电容` ✅ ｜ `circuit-01.mp4` ❌

**来源不明写「不明」，不要留空。** 留空与没记无法区分；写「不明」会促使后来人补查。事后补记只能是推测，下载当场记才是事实。

**Mixkit 素材必须记 id。** 详情页 slug 里的数字即video id，直链是：

```
https://assets.mixkit.co/videos/<id>/<id>-720.mp4
```

id 拼 URL 只要三秒，不记就永久丢失，只剩一个截断的英文 slug。

**只登记实际用过的。** 库不是下载缓冲区——下了一堆没用上的素材等于把来源问题推给未来。删掉不用的行和对应文件。

**图片优先实拍。** 有实拍素材时优先用实拍，比 AI 生图更可信（见 voiceframe 的「三类画面来源」）。
