## 素材来源与授权

**每个外部素材一行，包括项目自有的。**「内容」写画面里实际有什么（可检索的关键），不是复述文件名——库是跨项目共用的，别的项目靠这列判断能不能用。

来源不明时写「不明」，不要留空：留空和没记无法区分，而「不明」会促使后来人去查。

从共享库取的素材填 `库 id`，本地素材填路径；两者都要写来源和许可。

### 共享素材库

仓库内共用一份素材库，放在 `shared/video-assets/`。项目**不复制**，用软链接指过去：

```bash
mkdir -p assets
ln -s ../../../shared/video-assets/broll assets/broll      # 按需链接用到的类目
ln -s ../../../shared/video-assets/fonts assets/fonts
```

理由：同一批broll 素材在多个项目间重复下载过（实测两个项目 44 个文件逐字节相同，白占 282M）。软链接后 `frames.config.json` 里的相对路径不变，脚本无需改动。

代价：交付或迁移单个项目时，链接会断。**导出可交付工程前把链接展开成真实文件**，并在交付记录里写明。

库的台账在 `shared/video-assets/ASSETS.md`，新素材**下载当场**登记，不要等项目结束补。
